# 3D Car Models Directory

Drop your `.glb` or `.gltf` model files here!

Default target:
- `car.glb` (e.g., `public/models/car.glb`)

If `car.glb` is placed here, the application will automatically detect and load it, applying real-time custom paint formulations to meshes named `*body*`, `*paint*`, or `*exterior*`.

If no `.glb` file is present, the application seamlessly renders the built-in photorealistic, aerodynamic procedural supercar with active aerodynamics, laser matrix headlights, carbon-ceramic brakes, and customizable clearcoat materials.
